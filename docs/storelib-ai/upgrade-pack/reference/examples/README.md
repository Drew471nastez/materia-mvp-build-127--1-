# Example plans

These are **internal SitePlan proposals** showing the level of detail expected from a Storelib AI builder. They are NOT actual `.storelib` theme syntax. Claude should adapt output through the real Storelib compiler and existing APIs.

- `sneaker_store.plan.json` — 7 pages, category-specific branded retail direction, functional bindings marked as requirements.
- `digital_creator.plan.json` — a compact digital creator/storefront plan, deliberately different from the sneaker shop.

The validator tests structural coherence only; it is not a substitute for Storelib's theme validator or browser QA.
