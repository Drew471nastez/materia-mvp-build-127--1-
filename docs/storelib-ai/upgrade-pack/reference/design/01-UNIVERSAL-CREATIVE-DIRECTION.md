# Non-generic creative direction for any site category

A modern polished website is NOT a universal gradient hero + 3 feature cards. Use design principles from authentic public skills in `sources/`, but **choose contextually**: content architecture, composition, typography, photo direction, CTA hierarchy, interactions, motion, color system and content density should vary with user brief.

## Site archetypes with different composition
| User asks for | Appropriate structure |
|---|---|
| One-product store | Strong product hero, proof/benefits without fabricated claims, gallery, how it works, fit/FAQ, reviews only if real, purchase action, policy details; product route optional per brief |
| Apparel/sneaker multi-product store | Editorial brand hero, collection navigation, arrivals, product rail, catalog/category + product templates, size info, help/contact/policies |
| Digital product storefront | Product-led hero, screenshots/previews, sample files, features, terms/license, pricing, purchase/download/library journey |
| Coaching business | Differentiating introduction, approach, services/offers, outcomes without fake testimonials, consultation/contact/booking if real |
| Founder portfolio | Narrative/about, proof of work/case studies, projects, writing/contact, professional identity |
| SaaS landing | Product value + UI visual, key workflows, integrations (real), pricing (real), FAQ, signup, legal; dashboard routes only if requested |
| Agency | Focused positioning, work/case studies, capabilities, process, team, contact; varied editorial pacing |
| Restaurant/event | Menu/program, gallery, hours/location/reservation links if real, mobile CTA, FAQ; no fake booking system |
| Creator community/course | Creator identity, course catalog, course templates, membership offerings, protected access, library/dashboard when supported |
| Interactive webapp | Application IA, auth, flows, empty/loading/error states, components, persistent data and permission checks; not automatically a marketing storefront |

## Design output required
A compact creative brief with tone, precise target audience, type pairing options, color intentions, image/media directions, a reusable but unique component design system, page content architecture and motion personality. Avoid boilerplate copy, random icons, default purple gradients, huge uniform rounded cards and generic robot-looking hero imagery when not aligned with brand.

## Respect request size
A 'simple lead capture' site may have 4-7 substantial sections on one page. A full retail site may need more than 7 pages/templates. A full app may have 10+ views but no conventional marketing sections. Do NOT mechanically add pages or sections just to meet a number.
