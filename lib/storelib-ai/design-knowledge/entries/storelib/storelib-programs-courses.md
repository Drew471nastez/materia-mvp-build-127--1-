**Course page content from the product**: title, price, description, images; modules and lessons where the product exposes them. If the curriculum is not available as data, write it as blocks the creator edits, not invented module names presented as final.

**Format details** (self paced, live, start date, length) only from the product or the creator's brief.

**Enrol**: straight to the course's checkout. If the course is free, the action still uses the real flow.

**After purchase**: say where the course is accessed (the creator's Storelib account area), in one line.

**Avoid**: "Join 3,000 students", completion stats, "Certificate included" unless real, testimonials written by the model.
