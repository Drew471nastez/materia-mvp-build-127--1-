**Three proven shapes**
1. **Index list**: rows of project title, client, year, discipline in a tabular layout; hover or focus shows a preview image. Very fast to scan; works for large bodies of work.
2. **Grid**: images at a consistent ratio (or masonry for mixed), small captions under each. Best for visual disciplines.
3. **Sequence**: one project per viewport height, large image, title and a single line. Best for few, strong projects.

**Specs**: captions 13 to 14px; project titles 18 to 24px in the grid; case study headings 40 to 72px. Image ratio rules: pick one (4:5, 3:2, 16:10) for the grid and stick to it unless using masonry.

**Do**: keep chrome minimal so the work carries colour. Make every project reachable by keyboard with a visible focus state.

**Don't**: autoplaying carousels, skill bars, scroll hijacking, preloaders that hide the work for seconds.
