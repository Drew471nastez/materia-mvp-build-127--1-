A concept usually combines styles. Give each one a role so their rules do not fight.

- **Primary style** decides structure: grid, spacing, type scale, density.
- **Secondary style** decides surface: colour, imagery treatment, one or two signature details.
- **Accent style** (optional) supplies a single move: a marquee, a hover, a texture.

**Pairs that work**
- Editorial + luxury: magazine structure, luxury pace and palette.
- Swiss + industrial: grid discipline with mono specs and a safety accent.
- Minimalism + dark cinematic: few elements, dramatic imagery.
- Neo brutalism + playful: thick outlines, bright fills, springy buttons.
- Organic + light editorial: warm paper, serif reading type, natural photography.
- Typography led + agency: statement type with project index.

**Pairs that clash** (pick one): luxury + neo brutalism (pressure vs calm); glassmorphism + brutalism (translucent polish vs raw honesty); neumorphism + dark cinematic (soft low contrast on dark is unreadable).

**Resolving conflicts**: when two rules disagree, the primary style wins for layout and type; the secondary wins for colour and imagery. Write the resolution into the concept ("radius 0 everywhere except the playful sticker buttons") so every section follows the same answer.

Never combine more than three. Four styles is no style.
