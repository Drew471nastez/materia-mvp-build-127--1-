**Signals**: one illustration style throughout (line weight, palette, perspective); diagrams that explain how the product or service works; hand drawn lines connecting sections; a mascot only if the brand has one.

**Layouts**: a large illustrated opening with the real offer next to it; process explained as a drawn sequence; spot drawings in margins instead of icons.

**Type**: a soft serif or rounded grotesk; labels hand set only if lettering is part of the brand.

**Do**: use the creator's own illustration or plain SVG drawn for this site; give each meaningful drawing alt text.

**Don't**: generic blob people, isometric stock scenes, a different icon set per section.

**Combines with**: playful, education, publishing, children's products, community.
