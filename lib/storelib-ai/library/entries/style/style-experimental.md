**What it allows**: breaking the grid, overlapping elements, unconventional navigation, cursor effects, generative visuals, unusual scroll behaviour.

**What it still requires**: a normal, focusable link list somewhere (often the footer) so every page is reachable; readable text for anything that must be read (dates, prices, legal); reduced motion alternatives; no trap for keyboard users; acceptable performance on mid range phones.

**Method**: be experimental in one or two layers (layout and type, or motion and imagery) and conventional in the rest (forms, cart, checkout are never experimental).

**Good fits**: musicians, galleries, festivals, art schools, independent labels.

**Don't**: ship heavy canvas or WebGL backgrounds without a static fallback and a pause; run animations that cause jank on scroll; hide content behind mystery meat navigation with no labels.
