**Signals**: an opening statement set very large (80 to 200px on desktop, clamp down for phones), a project index, large case study images, a custom interaction (hover previews, cursor labels) used consistently.

**Type**: one display family with personality, used big; a neutral text face. Tight leading on display (0.9 to 1.05).

**Layout**: asymmetric grids, generous margins, images at different scales, text that sometimes overlaps images (with contrast protection).

**Motion**: purposeful and consistent: one reveal style for headings, one for images, one hover treatment. Page transitions only if they are fast (under 400ms) and never block reading.

**Don't**: use every trend at once. Pick one hero idea. Avoid generic "We are a creative studio" headlines; state a point of view or the actual offer.

**Combines with**: Swiss (precise studio), dark cinematic (production companies), typography led (branding studios).
