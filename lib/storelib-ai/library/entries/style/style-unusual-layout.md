**Signals**: content hanging from an off centre axis; an image overlapping the next section by a few rows; a vertical side rail with the site name or the section number; captions rotated 90 degrees in a margin; a headline that crosses two columns.

**Rules**: the strangeness needs a hidden grid (12 columns, a baseline) so it reads as intended. One or two unusual moves per page, repeated as a motif, not a different trick per section. On phones it collapses into a clear single column with one surviving signature (the rail becomes a top label, the overlap stays small).

**Do**: test every overlap at 375px; keep text on solid ground; keep focus order the visual order.

**Don't**: overlap text with text, rotate body copy, or make navigation hard to find.

**Combines with**: typography-led, portfolio, agency, fashion.
