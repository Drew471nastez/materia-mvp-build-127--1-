Each row: background / surface / text / muted text / accent. All text pairs pass 4.5:1 on the background.

| Mood | Values |
| --- | --- |
| Warm editorial | `#f7f3ec` / `#efe8dc` / `#1d1a16` / `#5c554b` / `#a33b20` |
| Quiet luxury | `#f4f1ea` / `#e9e4da` / `#1c1b19` / `#5d5952` / `#5a1a1a` |
| Mineral calm | `#eceae6` / `#dfddd8` / `#22272a` / `#53595c` / `#2f6f6a` |
| Swiss signal | `#ffffff` / `#f2f2f2` / `#111111` / `#555555` / `#d92b1c` |

| Forest | `#13201b` / `#1c2c25` / `#e7efe9` / `#a5b6ad` / `#d9b26b` |
| Pop | `#fff8ec` / `#ffe9c7` / `#1a1a1a` / `#4d4d4d` / `#ff4f8b` |
| Workshop | `#f1f0ec` / `#e4e2dc` / `#1b1b1b` / `#575757` / `#ff5a1f` |

**From a brand colour**: keep the brand colour as the accent. Derive neutrals by mixing a little of its hue into grey (warm brand, warm greys). Check the accent against both background and the text you will put on it.

**Count**: background, surface, text, muted, border, accent, and accent text. Seven tokens. Add a second accent only if the concept names a reason.
