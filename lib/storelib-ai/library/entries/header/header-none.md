**When**: a single page with one action (a pack launch, an event ticket page, a link in bio page), or an experimental site whose navigation lives elsewhere.

**Still required**: the brand name visible in the first screen; a way to reach important pages (footer links or an in page index); the cart if the site sells (a floating cart button); skip links still valid.

**Don't**: remove the header from a multi page site to look minimal. People rely on it to move around.
