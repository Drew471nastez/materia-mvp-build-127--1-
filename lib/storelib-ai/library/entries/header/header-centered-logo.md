**Variants**: logo centred above a centred link row (two tiers), or logo centred with menu button left and cart right (one tier, common on phones).

**Two tier**: logo 32 to 56px tall, links 12 to 14px caps below with 16px gap. Collapse the top tier on scroll to keep the header short.

**One tier**: grid `1fr auto 1fr` as in the split header so the logo is exactly centred.

**Watch out**: long wordmarks crowd the sides on phones. Set a max width on the logo (40 to 50% of viewport) and use the mobile logo if the theme has one.
