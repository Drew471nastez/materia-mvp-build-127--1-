**The pattern**: section after section with the same skeleton: centred heading, centred sub paragraph, grid of equal items. Or the same image left, text right row repeated four times.

**Evaluator checks**: a structural fingerprint per section (heading alignment, element sequence, grid column count); three or more consecutive sections with the same fingerprint, or more than half the page sharing one.

**Fix**: vary deliberately: a full bleed image band after a dense list; left aligned text after a centred statement; one large item instead of three small; a quote set huge; a table instead of cards. Each section's form should come from its content.
