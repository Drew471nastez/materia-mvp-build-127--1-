**The pattern**: a different icon above each feature card (lightning, shield, rocket, sparkles), icons in tinted rounded squares, mixed stroke and fill styles, emoji used as bullet icons, icons beside every label in the footer.

**Evaluator checks**: count of icon elements (svg in tiles, icon font classes, lucide or heroicons classes, emoji) relative to text blocks; icon tiles (icon inside a coloured rounded box) repeated in grids; emoji in headings.

**Fix**: remove icons that only decorate. Keep icons that aid recognition (cart, search, menu, play, social logos, a real category system). Use one set, one stroke width, one size scale, and give interactive icons accessible names.
